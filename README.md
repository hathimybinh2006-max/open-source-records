# Open Source Records - CSS Box Model Practice

Bài thực hành hoàn thiện CSS Box Model cho trang web Open Source Records.

## Các thuộc tính Box Model đã hoàn thiện
- **width & margin: auto**: Giới hạn độ rộng nội dung ở 620px và căn giữa trang web.
- **padding & order**: Tạo khung thẻ cho toàn bộ trang và từng mục sự kiện Tour Dates.
- **Menu điều hướng**: Thiết lập display: inline-block, margin-right, padding tạo các nút liên kết đẹp mắt.
- **Danh sách thành viên & Tour Dates**: Định dạng khoảng cách lề và đường viền trái nổi bật.
